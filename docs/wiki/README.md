# DCReg Bilingual Documentation

This directory contains a **GitHub-Pages-ready bilingual documentation page** for DCReg.

## Files

- [index.html](./index.html): tabbed bilingual documentation page with English and Chinese content

## How To Use

### Local preview

Open `docs/wiki/index.html` directly in a browser.

### GitHub Pages

If you enable **GitHub Pages** for this repository and set the publishing source to the `main` branch with the `/docs` folder, this page becomes the polished web documentation entry.

The repository also contains Markdown wiki source pages under:

- [../../wiki/Home.md](../../wiki/Home.md)
- [../../wiki/Home.zh-CN.md](../../wiki/Home.zh-CN.md)

Those files are also mirrored to the repository GitHub Wiki:

- https://github.com/JokerJohn/DCReg/wiki

The `docs/wiki/index.html` page remains useful as the polished bilingual web view because it supports the tabbed interface directly, while the GitHub Wiki is the default public-facing documentation entry.
