# Parking-Lot Example Data

This folder contains the small source frame used by
`dcreg_parking_lot_example`:

- `parkinglot_raw_1976_frame.pcd`
- `parkinglot_raw_1976_info.txt`

The prior map is intentionally not stored in the repository because it is
large. Download it from the data link in the repository README and place it
here as:

```text
DCReg/data/Parking-Lot-example/prior_map.pcd
```

The C++ example exports visualization artifacts to
`DCReg/data/Parking-Lot-example/visualization/`.
